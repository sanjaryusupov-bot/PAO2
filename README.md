# 📦 Дашборд «Аналитика расхождений СКЮ»

Streamlit-дашборд для анализа расхождений по товарной сверке: излишки, недостачи,
потери, проценты и выгрузка в Excel. Данные подтягиваются напрямую из Google Таблицы.
Демо-данные встроены прямо в код — отдельный файл с данными не нужен.

## Возможности

- 🔗 Автоматическая загрузка данных из Google Таблицы (лист «По товарная сверка»)
- 📤 Загрузка своего CSV/Excel файла как альтернативный источник
- 🧮 Все пустые значения автоматически приводятся к 0
- 🔘 Кнопки-фильтры: **Все / Излишки (−) / Недостачи (+) / С потерями**
- 📊 Аналитика в процентах: доля излишек, недостач и потерь (по количеству СКЮ и по объёму)
- 🍩 Круговая диаграмма структуры расхождений + топ-15 позиций по модулю расхождения
- 📥 Выгрузка в Excel (.xlsx) — отдельными листами по типу расхождения, либо только
  текущий отфильтрованный срез
- 🔍 Поиск по СКЮ / коду Магнита / баркоду / названию
- 🎨 Тёмный интерфейс с анимациями (карточки, прогресс-бары, графики)

## Структура проекта (всего 4 файла)

```
skyu-dashboard/
├── app.py                  # ВСЁ приложение в одном файле (демо-данные тоже внутри)
├── requirements.txt        # зависимости — обязателен для деплоя, отдельно от app.py
├── .streamlit/
│   └── config.toml         # тёмная тема (необязателен, можно не заливать)
└── README.md
```

`app.py` — это самодостаточный файл: логика, интерфейс и демо-данные (на случай,
если таблица недоступна) находятся внутри него. Больше ничего заливать не обязательно,
кроме `requirements.txt`, без которого Streamlit Cloud не поймёт, какие библиотеки ставить.

## Как это работает с Google Таблицей

Дашборд читает лист по прямой ссылке экспорта:

```
https://docs.google.com/spreadsheets/d/<ID_ТАБЛИЦЫ>/export?format=csv&gid=<GID_ЛИСТА>
```

Чтобы это работало, таблица должна быть открыта для доступа по ссылке:

1. В Google Таблице нажмите **«Настройки доступа»** (Share).
2. Выберите **«Все, у кого есть ссылка»** → роль **«Читатель»**.
3. Сохраните.

ID таблицы и GID листа уже подставлены по умолчанию (из вашей ссылки), но их можно
поменять прямо в боковой панели приложения.

Если доступ ограничен — дашборд покажет предупреждение и переключится на встроенные
демо-данные, пока вы не откроете доступ или не загрузите файл вручную.

## Запуск локально

```bash
git clone https://github.com/<ваш-логин>/skyu-dashboard.git
cd skyu-dashboard
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на `http://localhost:8501`.

## Как залить на GitHub (шаг за шагом)

**Вариант А — через терминал:**

```bash
# 1. Распакуйте архив skyu-dashboard.zip — получится папка skyu-dashboard
cd skyu-dashboard

# 2. Инициализируйте git и закоммитьте
git init
git add .
git commit -m "Дашборд аналитики расхождений СКЮ"
git branch -M main

# 3. Создайте пустой репозиторий на github.com (New repository, БЕЗ галочки README)
#    и подключите его:
git remote add origin https://github.com/<ваш-логин>/skyu-dashboard.git
git push -u origin main
```

**Вариант Б — через веб-интерфейс GitHub (без терминала):**

1. Создайте новый репозиторий на github.com.
2. Нажмите **«Add file» → «Upload files»**.
3. Перетащите **все 4 файла/папки** из распакованного архива:
   `app.py`, `requirements.txt`, `README.md`, папку `.streamlit` со вложенным `config.toml`.
   Важно: файлы должны лежать в **корне** репозитория, а не во вложенной папке.
4. Нажмите **«Commit changes»**.

## Деплой на Streamlit Community Cloud (бесплатно)

1. Зайдите на **https://share.streamlit.io** и авторизуйтесь через GitHub.
2. Нажмите **«New app»**.
3. Выберите:
   - **Repository**: `<ваш-логин>/skyu-dashboard`
   - **Branch**: `main`
   - **Main file path**: `app.py`
4. Нажмите **«Deploy»**.

Через 1–2 минуты приложение будет доступно по ссылке вида
`https://<ваш-логин>-skyu-dashboard.streamlit.app`.

При каждом `git push` в ветку `main` приложение автоматически пересобирается.

## Логика излишков/недостач

- **Излишки** — строки, где `Рассхождения < 0` (показываются со знаком «−»)
- **Недостачи** — строки, где `Рассхождения > 0` (без знака «−»)
- **Без расхождений** — строки, где `Рассхождения = 0`
- **С потерями** — строки, где `Потеряно > 0`

Данные из Google Таблицы кэшируются на 5 минут — используйте кнопку **«🔄 Обновить»**
в боковой панели, чтобы подтянуть свежие значения немедленно.

## Настройка под другую таблицу/лист

Откройте `app.py` и поменяйте константы в начале файла:

```python
DEFAULT_SHEET_ID = "1xpiftC3wy1QRDdBxklSbgl5Ph4eW0wGcl8as9mIZXuU"
DEFAULT_GID = "447006824"
DEFAULT_SHEET_NAME = "По товарная сверка"
```

Названия колонок определяются автоматически по ключевым словам (СКЮ, Код Магнита,
Баркод, Описания, Принято, Отгруженно, Сток, Потеряно, Рассхождения) — порядок и
регистр колонок в таблице значения не имеют.
